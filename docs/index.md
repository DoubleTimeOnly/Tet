# Tet

Tet is a personal learning and habit app for Android: spaced-repetition
flashcards, daily learning tasks with verifiable completion, habit tracking and
improv practice prompts.

All data is stored on your own device. An optional backup feature can copy
snapshots of that data to your own Google Drive.
